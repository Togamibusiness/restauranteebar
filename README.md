# Sistema de Gestão para Restaurantes e Bares

Bem-vindo ao sistema de gestão para restaurantes e bares. Este aplicativo foi projetado para ser eficiente, simples e fácil de usar, tanto em computadores quanto em dispositivos móveis.

## Descrição do Projeto

Este sistema oferece uma solução completa para gerenciar operações de restaurantes e bares, incluindo:

- **Gerenciamento de Mesas**: Controle de ocupação e status das mesas.
- **Pedidos**: Criação e acompanhamento de pedidos em tempo real.
- **Estoque**: Monitoramento de inventário e alertas de estoque baixo.
- **Relatórios**: Geração de relatórios para análise de desempenho.
- **Painel de Controle**: Visão geral das operações do restaurante.

## Tecnologias Utilizadas

- **Frontend**: React com TypeScript
- **Estilização**: Tailwind CSS
- **Backend**: Supabase para gerenciamento de dados
- **Build Tool**: Vite

## Instalação

Para rodar o projeto localmente, siga os passos abaixo:

1. **Clone o repositório**:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. **Navegue até o diretório do projeto**:
   ```sh
   cd <YOUR_PROJECT_NAME>
   ```

3. **Instale as dependências**:
   ```sh
   npm install
   ```

4. **Inicie o servidor de desenvolvimento**:
   ```sh
   npm run dev
   ```

## Uso

Após iniciar o servidor de desenvolvimento, você pode acessar o aplicativo em seu navegador através do endereço `http://localhost:8080`. O sistema é responsivo e pode ser usado tanto em computadores quanto em dispositivos móveis.

## Deploy

Para fazer o deploy deste projeto, recomendamos o uso do Vercel, que oferece uma integração fácil com repositórios Git e suporte para aplicações React.

### Passos para Deploy

1. Crie uma conta no [Vercel](https://vercel.com/).
2. Conecte seu repositório ao Vercel.
3. Configure as variáveis de ambiente necessárias.
4. Clique em "Deploy" para iniciar o processo.
5. Acesse sua aplicação através do URL fornecido pelo Vercel.

Para mais detalhes, consulte a [documentação do Vercel](https://vercel.com/docs).

## Framework Utilizado

Para o deploy deste projeto na Vercel, estamos utilizando o [Next.js](https://nextjs.org/). Next.js é um framework React que permite a renderização do lado do servidor e a geração de sites estáticos, oferecendo uma integração perfeita com a Vercel.
